# О VK Картах

VK Карты – картографический продукт компании VK, использующий базу открытых данных OpenStreetMap. Возможности продукта применяются в Mail, ВКонтакте, Юле и других продуктах корпорации. VK Карты также доступны широкому кругу разработчиков для использования в приложениях на различных платформах.

[Получите ключ и начните использовать VK Карты сейчас →](https://vk.ru/away.php?to=https%3A%2F%2Fmaps.vk.com%2Fru%2Fwelcome%2F)

## Решаемые задачи

Ниже — примеры типичных задач, которые вы можете выполнить с помощью VK Карт:

- Отобразить карту в приложении.
- Помочь пользователям с поиском адресов и интересных мест.
- Построить пешеходные, велосипедные и автомобильные маршруты между точками.
- Выбрать оптимальный маршрут для посещения нескольких мест.
- Помочь курьерам найти оптимальные пути к складам, а затем к заказчикам.
- Определить область, достижимую в течение заданного времени.
- Определить местоположение по IP-адресу.
- Определить высоту над уровнем моря, часовой пояс или почтовый индекс точки.

## Поддерживаемые платформы

Мы подготовили ряд SDK-библиотек для использования на наиболее популярных платформах:

- Maps SDK для Web (JavaScript)
- Maps SDK для Android
- Maps SDK для iOS

## Поддерживаемые языки

Мы стремимся к созданию полнофункциональных карт всего мира с максимальной поддержкой языков, интересующих наших клиентов. На текущий момент доступность того или иного языка определяется непосредственно самим языком и географическим регионом. Основные поддерживаемые языки — русский, английский и локальный в регионе.

## API

С помощью API VK Карт вы можете получать и использовать данные сервиса в любых приложения. Подробности — в разделе Использование API VK Карт.

## С чего начать?

С получения ключа доступа. Он необходим для работы с SDK или API VK Карт.

[Получите ключ сейчас →](https://vk.ru/away.php?to=https%3A%2F%2Fmaps.vk.com%2Fru%2Fwelcome%2F)

## Демосервер

Чтобы опробовать работу с VK Картами, вы можете воспользоваться демонстрационным сервером по адресу: `https://demo.maps.vk.com/api/{endpoint}?{params}`. Для отправки запросов к нему ключ доступа не требуется.

Этот сервер нельзя использовать для продуктовой эксплуатации ваших приложений. Его работоспособность не гарантируется, а суммарное число запросов в секунду к нему ограничено.

## Техническая поддержка

Если вам необходима помощь или возникли вопросы при использовании сервисов VK Карт, отправьте нам сообщения по адресу `support.maps@lists.vk.team`. Обращайтесь по этому же адресу для получения актуальной информации по имеющимся у вас ключам доступа и действиям с ними.
