# Поиск по почтовому индексу

**Поиск почтового индекса** — сервис, позволяющий находить:

- адреса, соответствующие запрошенному почтовому индексу;
- почтовый индекс по адресу;
- для России дополнительно можно запросить информацию об отделении Почты России, обслуживающем почтовый индекс.

`/postcode` — точка вызова сервиса поиска почтового индекса.

### Обязательные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `api_key` | `hex-string` | Доступ к сервисам. | `api_key=fa749bace6d8a3b1....` |
| `q` | `string` | Тело поискового запроса содержащее почтовый индекс, ref адреса или адрес для которого необходимо найти почтовый индекс. | `q=125167 q=020000003792BE0E q=Москва, Нарышкина, 5с1` |

### Дополнительные параметры запроса

| Имя поля | Формат | Описание | Пример |
| --- | --- | --- | --- |
| `fields` | `field1,`
`field2,...`
`fieldN` | Выбор полей, отображаемых в ответе. Возможные значения:
• `postoffice` — детальная информация об отделении Почты России, обслуживающем найденный почтовый индекс;
• `postcode` (по умолчанию) — найденный/искомый почтовый индекс;
• `addresses` (по умолчанию) — адреса, соответствующие найденному почтовому индексу. | `fields=postoffice,``postcode,addresses` |
| `addresses` | `string` | Формат ответа для поля addresses:
• `short` (по умолчанию) — краткое иерархичное представление адресов, использующих найденный почтовый индекс.
• `full` — детальное представление адресов, использующих найденный почтовый индекс (будет поддержан в будущем). | `addresses=full` |
| `isocode` | `2char` | Двухбуквенный код страны согласно [ISO 3166-1 alpha-2](https://vk.ru/away.php?to=https%3A%2F%2Fru.wikipedia.org%2Fwiki%2FISO_3166-1_alpha-2). На текущий момент поддерживается только `RU` – установлен по умолчанию. | `isocode=ru` |

## Ответ

### Параметры ответа

| Имя поля | Формат | Описание |
| --- | --- | --- |
| `request` | `string` | Запрос. |
| `postcode` | `string` | Найденный почтовый индекс. |
| `addresses` | `dict` | Адреса использующие найденный почтовый индекс. |
| `postoffice` | `dict` | Детальная информация об отделении Почты России, обслуживающем почтовый индекс. Подробное описание параметров см. в таблице ниже. |

### Описание полей postoffice

| Имя поля | Формат | Описание |
| --- | --- | --- |
| `address` | `string` | Полный найденный адрес. |
| `address_details` | `list` | Детальная информация о найденном адресе. |
| `opening_hours` | `list` | Время работы почтового отделения. |
| `ref` | `hex` | Идентификатор почтового отделения. Идентификатор объекта не является стабильным и может изменяться. |
| `pin` | `list` | Координаты почтового отделения (долгота и широта). |
