# Правовые вводные, проверенные по документам

Не юридическое заключение — выписка из первоисточников с датой проверки, чтобы не выяснять одно и то же дважды.

## Условия использования VK Карт

Источник: `https://help.mail.ru/legal/terms/maps/terms`, проверено 8 сентября 2026.

**Требований к атрибуции в тексте нет.** Слова «логотип», «атрибуция», «копирайт» в документе не встречаются ни
разу. Единственный механизм атрибуции, который мы наблюдаем, — логотип, который рисует сам SDK и который нельзя
скрыть (см. [`design-decisions.md`](design-decisions.md), Р-7).

**П. 3.9 — использование в стороннем ПО идёт через отдельный договор.** Дословно: «Использование отдельных
функций Сервиса на сторонних сайтах, в иных мобильных приложениях или иного программного обеспечения,
принадлежащих Пользователю, доступно с использованием API VK Карты. API VK Карты предоставляется Пользователю
отдельно по запросу и в порядке, определенном договором по предоставлению права использования API VK Карты».

Практический вывод: реальные условия для конечного приложения лежат не в этом публичном документе, а в договоре,
который пользователь заключает, получая ключ доступа. Это совпадает с нашей моделью — плагин ключей не
раздаёт, каждый потребитель получает свой.

**П. 3.7 — права на товарные знаки не предоставляются.** «Никакие положения настоящих Условий не предоставляют
Пользователю прав на использование фирменного наименования, товарных знаков, доменных имен и иных отличительных
знаков Компании… исключительно по письменному соглашению с Компанией».

Практический вывод: пункт про предоставление прав на брендирование, а не про упоминание. Название пакета
`vk_maps_mapkit` описывает, с чем работает обёртка, — это обычная практика для пакетов-обёрток. Риск не нулевой,
но и не блокирующий: если вендор попросит, переименование до первой публикации стоит недорого. Логотип VK в
материалах пакета (README, страница pub.dev) не используем.

**П. 4.2 — данные под лицензией OpenStreetMap.** «Компания осуществляет оперирование Сервисом на основании
открытой лицензии базы данных „OpenStreetMap“». Это объясняет, почему логотип-атрибуция вшит в SDK: обязательства
по атрибуции идут в том числе от ODbL, а не только от бренда VK. Ещё одна причина не давать возможности его
скрыть.

## Что из этого следует для плагина

1. Возможности скрыть логотип в API нет и не будет (Р-7).
2. Логотип VK в README и на странице пакета не размещаем; название пакета описательное.
3. В README пишем прямо: пакет неофициальный, ключ доступа пользователь получает сам у VK Карт, условия — по
   договору с VK.
