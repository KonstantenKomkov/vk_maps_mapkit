## Что мешает закрыть проект

1. **Android-артефакт недоступен.** Адреса из документации отдают 404,
   выкладка переехала на Nexus, координаты неизвестны. Пока это не решено,
   Android-часть нельзя ни собрать, ни проверить. Письмо вендору отправлено
   8 сентября 2026 — см. [`questions-for-vendor.md`](questions-for-vendor.md).
2. **Живая проверка не начата.** Ключ доступа у заказчика есть, проверка на
   устройстве запланирована отдельно. До неё карта проверена только тем, что
   пример собирается и запускается на симуляторе, а сама карта без ключа не
   рисуется.
3. **Структура `Layer` на Android не описана** в документации, поэтому слои
   стиля на Android отвечают `unsupported`.
4. **SDK 1.4.x нет в CocoaPods trunk.** На trunk выложены только версии
   `0.5.x`; актуальный релиз доступен подспеком из репозитория дистрибутива,
   поэтому приложению нужна строка `pod 'VKMapsSDK', :podspec => …` в
   `Podfile`. Через SPM всё подключается штатно.
5. **CocoaPods требует статической линковки.** SDK поставляется статическими
   `xcframework`, поэтому в `Podfile` нужен
   `use_frameworks! :linkage => :static` — с обычным `use_frameworks!`
   установка падает. Обнаружено при сборке примера 8 сентября 2026.
