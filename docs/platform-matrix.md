# Матрица поддержки платформ

Что работает на каждой платформе и почему. Строки заполняются по факту:
если возможности нет в нативном SDK, метод отвечает явной ошибкой
`unsupported`, а не молчаливым `null`.

Проверено 8 сентября 2026.

## Доступность артефактов

| Платформа | Артефакт | Состояние |
| --- | --- | --- |
| iOS | `VKMapsSDK` 1.4.4.14633 (CocoaPods) и `maps-mailru/vk-maps-distribution` (SPM) | доступен |
| Android | `ru.mail.maps:mapkit` по адресу из документации | **404**, координаты запрошены у вендора |
| Android | `com.vk.maps:maps-native-sdk` | в публичной части Nexus не найден |

## Поколения SDK

| Платформа | На чём построена реализация | Почему |
| --- | --- | --- |
| iOS | нативный `MapsNativeSDK` 1.4.4.14633 | доступен, есть DocC с полным API |
| Android | документированный `ru.mail.maps.sdk` | нативного Android SDK нет ни в документации, ни в публичной выкладке (решение Р-8) |

## Возможности

| Возможность | iOS | Android | Примечание |
| --- | --- | --- | --- |
| Показ карты, жесты | да | да | |
| Начальная камера, зум, поворот | да | да | наклон камеры на Android не документирован |
| Перемещение камеры с анимацией | да | да | на Android SDK не сообщает о завершении анимации — результат всегда `finished` |
| Вписывание области (`fitBounds`) | да | частично | на Android нет метода: карта центрируется на середине области |
| Границы видимой области | да | нет | `unsupported` |
| Координата по точке экрана | да | нет | `unsupported` |
| Точка экрана по координате | нет | нет | в нативном SDK есть только обратная проекция |
| Маркеры: добавить, изменить, удалить | да | да | на Android изменение — пересоздание маркера |
| Картинка маркера | по идентификатору изображения в стиле | значение встроенного перечисления | на Android произвольную картинку задать нельзя |
| Изображения стиля (`addStyleImage`) | да | нет | `unsupported` |
| Стиль: предопределённый | да | да | набор стилей на Android беднее |
| Стиль: JSON | да | нет | `unsupported` |
| Стиль: ссылка | да | да | |
| События касания и долгого касания | да | да | |
| Событие касания маркера | да | да | |
| События камеры | да | частично | на Android приходит только изменение зума |
| Режимы следования | да | нет | на Android режим переключается кнопкой `CurrentLocationView` |
| Индикатор пользователя | напрямую | через `LocationSource` | на Android позиция отдаётся источником, который дергает SDK |
| Источник GeoJSON | да | да | на Android обновление данных — пересоздание источника |
| Источник из ломаной маршрута | да | да | |
| Слои стиля (`addLayer`) | да | нет | структура `Layer` в документации Android не раскрыта — `unsupported` |
| Видимость слоя | да | нет | `unsupported` |
| Кластеризация | нет в SDK | есть в SDK | плагин считает кластеры на Dart (`VkClusterizer`) — так результат одинаков на обеих платформах |
| Логотип VK: положение и отступы | да | только на старте | скрывать нельзя нигде (решение Р-7) |
