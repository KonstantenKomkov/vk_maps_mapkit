# Матрица поддержки платформ

Что работает на каждой платформе и почему. Строки заполняются по факту:
если возможности нет в нативном SDK, метод отвечает явной ошибкой
`unsupported`, а не молчаливым `null`.

Проверено 8 сентября 2026; строки web добавлены 9 сентября 2026.

## Доступность артефактов

| Платформа | Артефакт | Состояние |
| --- | --- | --- |
| iOS | `VKMapsSDK` 1.4.4.14633 (CocoaPods) и `maps-mailru/vk-maps-distribution` (SPM) | доступен |
| Web | `MMR GL JS` — `https://maps.vk.com/sdk/js/0/mmr-gl.js` (проверено 9 сентября 2026, 0.2.43) | доступен, ключ не нужен для скачивания |
| Android | `ru.mail.maps:mapkit` по адресу из документации | **404**, координаты запрошены у вендора |
| Android | `com.vk.maps:maps-native-sdk` | в публичной части Nexus не найден |

## Сборка

| Платформа | Состояние |
| --- | --- |
| iOS | пример собирается и запускается на симуляторе; плагин регистрируется |
| Android | не собирается: артефакт SDK недоступен, поэтому имена пакетов в Kotlin-коде не проверены компилятором |
| Web | пример собирается (`flutter build web`); в браузере карта создаётся, стиль применяется, маркер по касанию появляется на карте с картинкой из стиля. Проверено 9 сентября 2026 в headless Chrome: SDK со своего адреса, стиль локальный, ключ фиктивный — поэтому тайлы VK не грузились |

## Поколения SDK

| Платформа | На чём построена реализация | Почему |
| --- | --- | --- |
| iOS | нативный `MapsNativeSDK` 1.4.4.14633 | доступен, есть DocC с полным API |
| Web | `MMR GL JS` 0.x (форк Mapbox GL JS) | единственный web-SDK VK Карт; документирован подробнее мобильных |
| Android | документированный `ru.mail.maps.sdk` | нативного Android SDK нет ни в документации, ни в публичной выкладке (решение Р-8) |

## Возможности

| Возможность | iOS | Android | Web | Примечание |
| --- | --- | --- | --- | --- |
| Показ карты, жесты | да | да | да | |
| Начальная камера, зум, поворот | да | да | да | наклон камеры на Android не документирован |
| Перемещение камеры с анимацией | да | да | да | на Android SDK не сообщает о завершении анимации — результат всегда `finished` |
| Вписывание области (`fitBounds`) | да | частично | да | на Android нет метода: карта центрируется на середине области |
| Границы видимой области | да | нет | да | на Android `unsupported` |
| Координата по точке экрана | да | нет | да | на Android `unsupported` |
| Точка экрана по координате | нет | нет | да | в мобильных SDK есть только обратная проекция; на web `project` возвращает `null` для точки за камерой |
| Маркеры: добавить, изменить, удалить | да | да | да | на Android изменение — пересоздание маркера; на web все маркеры лежат одним слоем `symbol` (решение Р-12) |
| Картинка маркера | по идентификатору изображения в стиле | значение встроенного перечисления | по идентификатору изображения в стиле | на Android произвольную картинку задать нельзя |
| Изображения стиля (`addStyleImage`) | да | нет | да | на web PNG декодируется браузером и уходит в `map.addImage` |
| Стиль: предопределённый | да | да | частично | на web есть только `main`, `dark`, `simple`; остальные отвечают `UnsupportedError` |
| Стиль: JSON | да | нет | да | на Android `unsupported` |
| Стиль: ссылка | да | да | да | |
| События касания и долгого касания | да | да | да | долгое касание на web — событие `contextmenu`: правая кнопка мыши или долгое нажатие на сенсорном экране |
| Событие касания маркера | да | да | да | на web маркер под точкой ищется через `queryRenderedFeatures` |
| События камеры | да | частично | да | на Android приходит только изменение зума |
| Режимы следования | да | нет | да | на web режим считает плагин по координатам из `setUserLocation` (решение Р-10); на Android режим переключается кнопкой `CurrentLocationView` |
| Индикатор пользователя | напрямую | через `LocationSource` | слоями плагина | на web рисуются точка и круг точности; направление в отрисовке не участвует |
| Источник GeoJSON | да | да | да | на Android обновление данных — пересоздание источника |
| Источник из ломаной маршрута | да | да | да | на web ломаная разбирается на Dart-стороне: web-SDK принимает только GeoJSON |
| Слои стиля (`addLayer`) | да | нет | да | структура `Layer` в документации Android не раскрыта — `unsupported` |
| Видимость слоя | да | нет | да | на Android `unsupported` |
| Кластеризация | нет в SDK | есть в SDK | есть в SDK | плагин считает кластеры на Dart (`VkClusterizer`) — так результат одинаков на всех платформах |
| Логотип VK: положение и отступы | да | только на старте | да | скрывать нельзя нигде (решение Р-7); на web логотип рисует `LogoControl` самого SDK |
| Компас, кнопки зума | да | да | да | на web это `NavigationControl` |
| Кнопка «текущая позиция» | да | да | да | на web это `GeolocateControl`, он берёт координаты у браузера сам |
| Язык подписей (`locale`) | да | да | нет | web-SDK такого параметра не имеет: его `locale` — перевод строк интерфейса, а не язык карты |
| Отступы камеры (`padding`) | да | да | да | |
| Ограничение зума (`minZoom`, `maxZoom`) | да | да | да | |
| `logoIgnoresSafeArea` | да | нет | нет | на web безопасной области нет |
| `featuresSelectionMode` | да | да | нет | в web-SDK выбора объектов стиля нет; значение принимается и ни на что не влияет |
| `VkAnimationDurationMode.atMost` | да | да | как `exact` | `easeTo` всегда тратит ровно заданное время |
| Тип platform view (`VkPlatformViewType`) | не применяется | применяется | не применяется | на web карта живёт в `HtmlElementView` |
