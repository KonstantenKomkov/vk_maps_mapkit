# Чек-лист живой проверки

Проверки, которые нельзя закрыть автотестами: их результат виден только на
устройстве. Пока строка не заполнена датой и результатом, возможность
считается непроверенной, даже если код написан и тесты зелёные.

Запуск: `make example-ios` / `make example-android` / `make example-web` с
ключом в `VK_MAPS_API_KEY`, затем `flutter test integration_test` там же.

Web проверяется в браузере вручную: интеграционные тесты Flutter не умеют
заглядывать внутрь `HtmlElementView`, а карта живёт именно там.
