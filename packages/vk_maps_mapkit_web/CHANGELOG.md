# Изменения `vk_maps_mapkit_web`

## 0.1.0 — не выпущено

- Первая версия пакета: карта, камера, маркеры, стили, источники, слои,
  индикатор пользователя и события поверх MMR GL JS.
- Данные в SDK передаются через `JSON.parse` (решение Р-14): поэлементная
  укладка отправляла в карту внутреннее представление объектов Dart, и
  маркеры не появлялись.
- Отсутствие картинки маркера в стиле больше не молчаливое: приходит ошибка
  `style-image-missing` с именем изображения. Сообщается только про
  картинки маркеров приложения — о собственных значках стиля VK плагин
  молчит.
- Декодер ломаной маршрута переписан без побитовых операций: в браузере они
  считаются на 32 битах, и часть точек уезжала к полюсу (решение Р-15).
