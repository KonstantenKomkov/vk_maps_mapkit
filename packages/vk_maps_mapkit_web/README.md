# vk_maps_mapkit_web

Web-реализация плагина `vk_maps_mapkit` поверх `MMR GL JS` — JavaScript SDK
VK Карт.

Подключать напрямую не нужно: пакет попадает в приложение вместе с фасадом
[`vk_maps_mapkit`](../vk_maps_mapkit).

## Как подключается библиотека

Скрипт и стили SDK загружаются сами при `VkMaps.init(...)`, поэтому править
`web/index.html` не требуется. Если библиотека уже есть на странице —
подключена вручную или собрана в бандл — используется она.

Адрес и версию можно задать до инициализации:

```dart
import 'package:vk_maps_mapkit_web/vk_maps_mapkit_web.dart';

VkMapsSdkLoader.baseUrl = 'https://maps.vk.com/sdk/js'; // по умолчанию
VkMapsSdkLoader.version = '0.2.43'; // по умолчанию '0' — последняя 0.x.x
```

Импорт web-пакета в кроссплатформенном приложении нужно прятать за условным
импортом: на Android и iOS этого пакета в сборке нет.

## Чем реализация отличается от мобильных

- маркеры рисуются одним слоем `symbol`: картинка берётся из стиля по
  `imageId`, точка привязки — из `icon-anchor`, порядок — из
  `symbol-sort-key`;
- режимов следования в JavaScript SDK нет, их считает плагин по координатам
  из `setUserLocation`;
- индикатор пользователя — слои плагина: точка и круг точности;
- готовые стили доступны только те, что есть в web-SDK (`main`, `dark`,
  `simple`); остальные отвечают явной ошибкой;
- ломаная маршрута разбирается на Dart-стороне: источники web-SDK принимают
  только GeoJSON.

Полный перечень различий — в
[матрице поддержки платформ](../../docs/platform-matrix.md).

## Картинка маркера

Маркер ссылается на изображение стиля по `imageId` — как на мобильных
платформах. Если такого изображения в стиле нет, маркер не рисуется, а
приложение получает ошибку `style-image-missing` с именем картинки:
положите её через `controller.addStyleImage` до показа маркеров. Изображения
переживают смену стиля: плагин возвращает их в новый стиль сам.

Ошибка приходит только про картинки, на которые ссылаются маркеры
приложения. Стиль VK просит у SDK и свои значки — организаций, знаков,
переработки, — и о них плагин молчит: это дело стиля, а не приложения.

## Логотип VK

Логотип показывает сам SDK (`LogoControl`). Скрыть его нельзя — как и на
мобильных платформах; можно только выбрать угол и отступы.
