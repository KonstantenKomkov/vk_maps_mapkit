# vk_maps_api

Клиент REST-сервисов VK Карт на чистом Dart, без зависимости от Flutter:
геокодинг, подсказки, поиск мест, маршруты, изохроны, матрица достижимости,
профиль высот, определение по IP, часовой пояс, почтовый индекс и статичная
карта.

> Неофициальный пакет. Ключ доступа выдаёт VK Карты; до его получения часть
> сервисов доступна на демонстрационном сервере.

Пакет находится в разработке, публичного релиза ещё нет.
